# C++ Practice Code

这个仓库包含了我的C++学习练习代码和TJUOJ题目解答。

## 目录结构

- `TJUOJ/` - TJU Online Judge 题目解答
  - 包含各种算法题目的C++实现
  - 涵盖数据结构、算法、动态规划等多个主题

## 题目分类

### 基础题目
- 数据输入输出
- 循环与条件判断
- 数组与字符串操作

### 数据结构
- 栈和队列（括号匹配、队列和栈等）
- 树和图（细胞数BFS/DFS等）
- 字符串处理

### 算法题目
- 排序算法（成绩排序等）
- 搜索算法（DFS/BFS）
- 动态规划（斐波那契数、最长公共子序列等）
- 贪心算法（合并果子等）
- 数学问题（进位、分数加法等）

## 使用说明

每个`.cpp`文件都是独立的题目解答，可以直接编译运行。

```bash
# 编译
g++ filename.cpp -o output

# 运行
./output
```
