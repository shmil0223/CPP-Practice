## 3 口诀：单 算 关 逻 赋

按优先级从高到低排列：

1. **单** (单目)：`!`、`++`、`--`、`*`(取值)、`&`(取址)

   （同一级别：右边的先算）

2. **算** (算术)：`*`、`/`、`%`、`+`、`-`

3. **关** (关系)：`>`、`<`、`>=`、`==`、`!=`

4. **逻** (逻辑)：`&&` (高) > `||` (低)

5. **赋** (赋值)：`=`、`+=`、`-=`

**“先算出数，再比较大小，然后逻辑判断，最后赋值保存。”**

1. **括号无敌**：`()` 永远最高。

2. **非与或**：逻辑运算内部顺序是 `!` > `&&` > `||`。

3. **搞不清就加括号**

4. ||遇到非零数就短路；&&遇到零就短路

5. **题目**: 设 `int a[]={1,2,3,4,5,6,7}, *p=a, *q=&a[5];` 则下列表达式中值不等于 5 的是 ( )。

   > 注意此处的*q=&a[5],意思是int *q = &a[5]

   - **答案**: **A**
   - **解析**:
     - `p` 指向 `a[0]` (1)，`q` 指向 `a[5]` (6)。
     - **A**: `*q--`。后置自减，先返回 `q` 指向的值 (6)，然后 `q` 减 1。**值为 6**。右结合，相当于*(q--)
     - **B**: `*--q`。前置自减，`q` 先减 1 指向 `a[4]` (5)，然后取值。值为 5。
     - **C**: `--*q`。取 `q` 指向的值 (6)，然后数值减 1。值为 5（且修改了数组内容）。
     - **D**: `q-p`。指针相减，表示元素个数差。`&a[5] - &a[0] = 5`。值为 5。
     - 题目问**不等于 5** 的，故选 A。

## 9 动态联编

**题目**: 下列关于动态联编的描述中，错误的是 ( )。

- **答案**: **D**

- **解析**:

  - **D**: 动态联编（多态）是在**运行时**确定调用哪个函数的，而不是编译时。编译时确定属于静态联编。

  - 动态联编（Dynamic Binding），也称为运行时联编，它指的是在程序运行时决定调用哪一个方法或函数的过程。这是与静态联编（编译时联编）相对的，后者是在编译时就已经确定了调用哪个方法。

  - 在 C++ 中，实现动态联编通常需要满足三个条件：

    1. **继承**：存在基类和派生类的关系。
    2. **虚函数**：基类中将函数声明为 `virtual`。
    3. **指针或引用**：通过基类的指针或引用来调用虚函数。

  - 在动态联编中，方法的调用是延迟到程序运行时才决定的，通常与继承和多态的特性相关。具体来说，它通常发生在：

    1. **多态性**：当子类重写**（override）**父类的方法时，通过父类指针或引用来调用子类的方法。这时，具体调用哪个方法是在运行时根据对象的实际类型来决定的。
    2. **虚函数**：为了实现动态联编，通常需要在父类中使用`virtual`关键字声明函数为虚函数。虚函数确保了即使通过父类的指针或引用调用方法，实际调用的仍然是子类的重写版本。

    ##### 示例：

    ```c++
    #include <iostream>
    using namespace std;

    class Base {
    public:
        virtual void show() {  // 虚函数
            cout << "Base class" << endl;
        }
    };

    class Derived : public Base {
    public:
        void show() override {  // 重写父类的 show 函数
            cout << "Derived class" << endl;
        }
    };

    int main() {
        Base* basePtr;
        Derived derivedObj;

        basePtr = &derivedObj;
        basePtr->show();  // 调用的是 Derived 类的 show 函数，而不是 Base 类的 show

        return 0;
    }
    ```

    ##### 解释：

    - 在上面的代码中，`Base` 类的 `show` 函数被声明为虚函数。

    - 即使 `basePtr` 是指向 `Base` 类的指针，但它指向的是 `Derived` 类的对象。

    - 因为 `show` 是虚函数，动态联编机制会在运行时选择调用 `Derived` 类中的 `show` 方法，而不是 `Base` 类的 `show` 方法。

    - `override` 专门用于**辅助编译器检查虚函数重写（Override）的正确性**。

      **显式地告诉编译器，“我这个函数是要重写基类的虚函数的，请帮我检查一下有没有写错。”**

    ##### 动态联编的优点：

    - **灵活性**：程序可以根据运行时的具体对象类型做出不同的行为决策。
    - **多态性支持**：允许通过基类指针或引用访问派生类的成员函数，实现代码的复用和扩展性。

## 13 虚函数

### **一、C++ 运行时多态成立的条件：**

1. **继承**
2. **基类函数为 virtual**
3. **通过基类指针或引用调用**

```
Base* p = new Derived();
p->func();   // 多态
```

❌ 对象名直接调用不构成多态
❌ 普通函数不构成多态

------

### 二、虚函数（virtual function）

#### 1️⃣ 定义（一句话）

> 虚函数是在运行期根据对象的实际类型决定调用哪个函数的成员函数。

------

#### 2️⃣ 作用

- 实现 **运行时多态**
- 解决“基类指针指向派生类对象，却调用基类函数”的问题

------

#### 3️⃣ 基本用法

```C++
class Base {
public:
    virtual void show() {
        cout << "Base\n";
    }
};

class Derived : public Base {
public:
    void show() {
        cout << "Derived\n";
    }
};
```

------

#### 4️⃣ 重要规则（高频考点）

- 只有 **基类函数** 需要写 `virtual`
- 派生类同名函数 **自动是虚函数**
- 构造函数 ❌ 不能是虚函数
- 虚函数调用发生在 **运行期**

------

### 三、动态联编 vs 静态联编

| 类型     | 绑定时间 | 调用依据      |
| -------- | -------- | ------------- |
| 静态联编 | 编译期   | 指针/变量类型 |
| 动态联编 | 运行期   | 对象实际类型  |

📌 **虚函数 = 动态联编**

------

### 四、虚析构函数（重点 + 易错）

#### 1️⃣ 为什么必须要虚析构

```C++
Base* p = new Derived();
delete p;
```

- 如果析构函数 **不是 virtual**
- 只调用 `Base` 析构
- `Derived` 析构不执行
- 👉 **资源泄漏**

------

#### 2️⃣ 正确写法（必背）

```C++
class Base {
public:
    virtual ~Base() = default;
};
```

📌 **凡是用于多态的基类，析构函数必须是 virtual**

------

#### 3️⃣ 析构顺序（考试常问）

```
Derived 析构 → Base 析构
```

------

#### 4️⃣ 常见误区

❌ “基类没资源，不用虚析构”
✅ 错，只和 **是否多态** 有关

❌ “派生类析构也要写 virtual”
✅ 错，基类是 virtual 即可

### 六、override（加分点）📌 **推荐写，但不是必须**

```C++
class Derived : public Base {
public:
    void show() override;
};
```

作用：

- 编译期检查是否真正重写
- 防止函数签名写错

------

### 七、虚函数 vs 虚析构（对照表）

| 项目     | 虚函数   | 虚析构       |
| -------- | -------- | ------------ |
| 目的     | 行为多态 | 安全释放对象 |
| 是否必须 | 按需求   | 多态基类必须 |
| 忘写后果 | 调用错误 | 内存泄漏     |
| 绑定方式 | 动态联编 | 动态联编     |

------

### 八、判断题速判口诀（非常好用）

- **基类指针 + virtual → 多态**
- **delete 基类指针 → 析构必须 virtual**
- **构造函数不能 virtual**
- **对象切割 → 无多态**

------

### 九、终极考试总结（一句话背诵）

> C++ 中通过基类指针或引用调用虚函数实现运行时多态，虚函数采用动态联编；凡是作为多态基类的类，其析构函数必须声明为 virtual，以保证派生类对象被正确析构，防止资源泄漏

### `strcpy` 是什么？

`strcpy` 是 **C / C++ 中的字符串拷贝函数**，**把一个以 \0 结尾的字符串，复制到另一块字符数组中**。

```c++
strcpy(目标地址, 源字符串);
```

### 函数原型

```C++
char* strcpy(char* dest, const char* src);
```

含义：

- `dest`：目标字符串（必须有足够空间）
- `src`：源字符串（**以 `'\0'` 结尾**）
- 返回值：`dest`

------

### 在你代码中的作用

你的代码：

```
name = new char[strlen(n) + 1];
strcpy(name, n);
```

#### 执行流程拆解

1️⃣ `strlen(n)`

- 计算字符串 `n` 的长度
- **不包含 \0**

2️⃣ `+1`

- 给字符串结尾的 `'\0'` 留空间
  👉 **这是关键细节，考试常考**

3️⃣ `new char[...]`

- 在堆上分配一块足够大的空间

4️⃣ `strcpy(name, n)`

- 把 `n` 中的字符 **逐个复制**
- **包括结尾的 '\0'**
- 最终 `name` 成为 `n` 的一份完整拷贝

## 17 C语言字符串详解

### 一、定义

**C 语言字符串 = 以 '\0' 结尾的字符数组**

```
char s[] = "hello";   // 实际：h e l l o \0
```

------

### 二、两种常见写法（必区分）

### 1️⃣ 字符数组

```
char s[] = "hi";
```

- 本质：数组
- 内容：**可修改**
- 数组名不可赋值

------

### 2️⃣ 字符指针

```
char *p = "hi";
```

- 指向：字符串常量区
- 内容：**不可修改**（改了是未定义行为）
- 指针本身可重新指向

------

### 三、数组名的本质（高频考点）

```
char s[] = "hi";
```

- `s` **不是指针变量**
- 在表达式中会 **退化为 char \*（指向首元素）**
- 但 `s` **不能被赋值**

```
*s == s[0];   // 成立
s = "ok";     // ❌
```

------

### 四、`sizeof` 对比（经典考点）

```
char s[] = "hi";
char *p = s;

sizeof(s);   // 3（含 '\0'）
sizeof(p);   // 8（64 位系统）
```

------

### 五、字符串函数要点

- `strlen`：不包含 `'\0'`
- `strcpy / strcat`：**不检查越界**
- `strcmp`：比较内容，**不能用 ==**

------

### 六、常见坑（一句话）

- 忘记 `'\0'` → 未定义行为
- `char *p = "abc"` 后修改 `p[0]` → 错
- 用 `==` 比较字符串 → 错

------

### 七、一句话总结

> **`C 字符串是字符数组，靠 '\0' 结束；数组名不是指针，但在表达式中像指针。`**

```
size_t strlen(const char *s);
```

- 作用：返回字符串长度
- **不包含 '\0'**

```
strlen("abc");   // 3
```

⚠️ 参数必须是**以 '\0' 结尾的字符串**

------

#### 2 `strcpy` —— 字符串拷贝

```
char *strcpy(char *dst, const char *src);
```

- 将 `src` 复制到 `dst`
- 会把 `'\0'` 一起复制
- 返回 `dst`

```
char a[10];
strcpy(a, "hi");
```

⚠️ **不检查目标数组大小 → 易溢出**



#### 3 `strcat` —— 字符串拼接

```
char *strcat(char *dst, const char *src);
```

- 把 `src` 接到 `dst` 后面
- 返回 `dst`

```
char s[20] = "hi";
strcat(s, "!");
```

⚠️ `dst` 必须有足够空间



------

#### 4 `strcmp` —— 字符串比较（重点）

```
int strcmp(const char *s1, const char *s2);
```

返回值含义：

- `< 0`：`s1 < s2`
- `= 0`：相等
- `> 0`：`s1 > s2`

```
strcmp("abc", "abc");  // 0
```

⚠️ **不能用 == 比较字符串内容**

#### 七、速记对照表（笔记用）

| 函数     | 作用 | 注意点       |
| -------- | ---- | ------------ |
| `strlen` | 长度 | 不含 `'\0'`  |
| `strcpy` | 拷贝 | 不检查越界   |
| `strcat` | 拼接 | 目标空间要够 |
| `strcmp` | 比较 | 不能用 `==`  |

------

#### 一句话总结

> 长度用 strlen，拷贝用 strcpy，
>
> 比较用 strcmp，拼接用 strcat，
>
> 带 n 的函数要小心 '\0'。

## 18 冒泡排序

## 19 switch语句

**作用：**执行多条件分支语句

**语法：**

```c++
switch(表达式)

{

	case 结果1：执行语句;break;

	case 结果2：执行语句;break;

	...

	default:执行语句;break;

}

```



**示例：**

```c++
int main() {

	//请给电影评分 
	//10 ~ 9   经典   
	// 8 ~ 7   非常好
	// 6 ~ 5   一般
	// 5分以下 烂片

	int score = 0;
	cout << "请给电影打分" << endl;
	cin >> score;

	switch (score)
	{
	case 10:
	case 9:
		cout << "经典" << endl;
		break;
	case 8:
		cout << "非常好" << endl;
		break;
	case 7:
	case 6:
		cout << "一般" << endl;
		break;
	default:
		cout << "烂片" << endl;
		break;
	}

	system("pause");

	return 0;
}
```



> 注意1：switch语句中表达式类型只能是整型或者字符型

> 注意2：**case里如果没有break，那么程序会一直向下执行**

> 总结：与if语句比，对于多条件判断时，switch的结构清晰，执行效率高，缺点是switch不可以判断区间
