1. **题目**: 下列变量定义语句中合法的是 ( )。

   - **答案**: **A**

   - **解析**:

     - 这道题的正确答案是 **A**。

       - **A. double _a=1-.1e-1; —— [正确]**
         - **变量名合法性：** `_a` 是合法的标识符。在 C/C++ 中，变量名必须以字母或下划线开头，不能以数字开头。
         - **数值合法性：** `.1e-1` 是合法的浮点数科学计数法表示。
           - `.1` 代表 $0.1$。
           - `e-1` 代表乘以 $10^{-1}$。
           - 所以 `.1e-1` 等于 $0.01$。整个表达式 `1-.1e-1` 是合法的算术表达式。
       - **B. double b=1+5e2.5; —— [错误]**
         - **数值非法：** 在科学计数法中，`e` 或 `E` 后面的指数部分**必须是整数**。`2.5` 是小数，因此 `5e2.5` 是非法的写法。
       - **C. long do=0xfdaL; —— [错误]**
         - **变量名非法：** `do` 是 C/C++ 语言的**关键字**（用于 `do-while` 循环），不能用作变量名。
       - **D. float 2_and=1-e-3; —— [错误]**
         - **变量名非法：** `2_and` 以数字 `2` 开头。标识符**不能以数字开头**。
         - **数值写法可能有误：** `1-e-3` 这种写法在语法上会被解析为 `1` 减去变量 `e` 再减去 `3`。如果题目意图是表示科学计数法，正确的写法应该是 `1e-3`（即 $1 \times 10^{-3}$），单独的 `e-3` 不是合法的数字字面量。

       综上所述，只有 **A** 是合法的变量定义语句。

2. **题目**: 设 `int a(2), b(3);` 表达式 `a||++b&&0;` 执行完毕后，表达式的值和 `b` 的值分别是 ( )。

   - **答案**: **C**

   - **解析**:

     - 考察逻辑运算符的短路特性和优先级。

     - 优先级 `&&` 高于 `||`，表达式等价于 `a || (++b && 0)`。

     - 首先计算 `||` 左侧的 `a`，值为 2 (真)。

     - 根据 `||` 的短路特性，既然左侧为真，整个表达式的结果即为真（值为 1），右侧的 `(++b && 0)` **不会被执行**。

     - 因此，`b` 的值保持 3 不变，表达式的值为 1。

       >口诀：单 算 关 逻 赋

       按优先级从高到低排列：

       1. **单** (单目)：`!`、`++`、`--`、`*`(取值)、`&`(取址)
       2. **算** (算术)：`*`、`/`、`%`、`+`、`-`
       3. **关** (关系)：`>`、`<`、`>=`、`==`、`!=`
       4. **逻** (逻辑)：`&&` (高) > `||` (低)
       5. **赋** (赋值)：`=`、`+=`、`-=`

       **“先算出数，再比较大小，然后逻辑判断，最后赋值保存。”**

       1. **括号无敌**：`()` 永远最高。
       2. **非与或**：逻辑运算内部顺序是 `!` > `&&` > `||`。
       3. **搞不清就加括号**

3. **题目**: 以下选项中，与 `k=n++` 完全等价的表达式是 ( )。

   - **答案**: **A**
   - **解析**:
     - `k=n++` 的含义是：先将 `n` 的值赋给 `k`，然后 `n` 自增 1。
     - **A**: `k=n, ++n;` 利用逗号表达式，先执行 `k=n`，再执行 `++n`，效果一致。
     - **B**: 语法错误。
     - **C**: `k=++n` 是先自增再赋值（`n` 变大后赋给 `k`）。
     - **D**: `k+=n+1` 逻辑完全不同。

6. **题目**: 设 `int a[]={1,2,3,4,5,6,7}, *p=a, *q=&a[5];` 则下列表达式中值不等于 5 的是 ( )。

   > 注意此处的*q=&a[5],意思是int *q = &a[5]

   - **答案**: **A**
   - **解析**:
     - `p` 指向 `a[0]` (1)，`q` 指向 `a[5]` (6)。
     - **A**: `*q--`。后置自减，先返回 `q` 指向的值 (6)，然后 `q` 减 1。**值为 6**。
     - **B**: `*--q`。前置自减，`q` 先减 1 指向 `a[4]` (5)，然后取值。值为 5。
     - **C**: `--*q`。取 `q` 指向的值 (6)，然后数值减 1。值为 5（且修改了数组内容）。
     - **D**: `q-p`。指针相减，表示元素个数差。`&a[5] - &a[0] = 5`。值为 5。
     - 题目问**不等于 5** 的，故选 A。

13. **题目**: 下列关于动态联编的描述中，错误的是 ( )。

    - **答案**: **D**

    - **解析**:

      - **D**: 动态联编（多态）是在**运行时**确定调用哪个函数的，而不是编译时。编译时确定属于静态联编。

      - 动态联编（Dynamic Binding），也称为运行时联编，是面向对象编程中的一个概念。它指的是在程序运行时决定调用哪一个方法或函数的过程。这是与静态联编（编译时联编）相对的，后者是在编译时就已经确定了调用哪个方法。

      - 在 C++ 中，实现动态联编通常需要满足三个条件：

        1. **继承**：存在基类和派生类的关系。
        2. **虚函数**：基类中将函数声明为 `virtual`。
        3. **指针或引用**：通过基类的指针或引用来调用虚函数。

      - 在动态联编中，方法的调用是延迟到程序运行时才决定的，通常与继承和多态的特性相关。具体来说，它通常发生在：

        1. **多态性**：当子类重写（override）父类的方法时，通过父类指针或引用来调用子类的方法。这时，具体调用哪个方法是在运行时根据对象的实际类型来决定的。
        2. **虚函数**：为了实现动态联编，通常需要在父类中使用`virtual`关键字声明函数为虚函数。虚函数确保了即使通过父类的指针或引用调用方法，实际调用的仍然是子类的重写版本。

        ##### 示例：

        ```c++
        #include <iostream>
        using namespace std;

        class Base {
        public:
            virtual void show() {  // 虚函数
                cout << "Base class" << endl;
            }
        };

        class Derived : public Base {
        public:
            void show() override {  // 重写父类的 show 函数
                cout << "Derived class" << endl;
            }
        };

        int main() {
            Base* basePtr;
            Derived derivedObj;

            basePtr = &derivedObj;
            basePtr->show();  // 调用的是 Derived 类的 show 函数，而不是 Base 类的 show

            return 0;
        }
        ```

        ##### 解释：

        - 在上面的代码中，`Base` 类的 `show` 函数被声明为虚函数。

        - 即使 `basePtr` 是指向 `Base` 类的指针，但它指向的是 `Derived` 类的对象。

        - 因为 `show` 是虚函数，动态联编机制会在运行时选择调用 `Derived` 类中的 `show` 方法，而不是 `Base` 类的 `show` 方法。

        - `override` 是 **C++11** 标准引入的一个保留字（specifier），专门用于**辅助编译器检查虚函数重写（Override）的正确性**。

          简单来说，它的作用就是：**显式地告诉编译器，“我这个函数是要重写基类的虚函数的，请帮我检查一下有没有写错。”**

        ##### 动态联编的优点：

        - **灵活性**：程序可以根据运行时的具体对象类型做出不同的行为决策。
        - **多态性支持**：允许通过基类指针或引用访问派生类的成员函数，实现代码的复用和扩展性。

        ##### 动态联编的缺点：

        - **性能开销**：因为函数调用是在运行时通过虚函数表（VTable）查找的，所以会比静态联编略慢。

        总结来说，动态联编使得程序可以在运行时决定调用哪个方法，增强了灵活性和可扩展性。

- **题目意图**: 输入一个 10~10000 的数，判断其各位数字是否全部相同（如 222 是，232 否）。

- **代码补全**:

  ```c++
  // ... 之前的代码 ...
  do {
      cout << "请输入一个 10~10000 的整数：";
      cin >> a;
  } while (a < 10 || a > 10000); // 第一空：输入不在范围内则继续循环

  do {
      r1 = a % 10;       // 取当前最后一位
  ```

### 1. `if(!f)`：检查文件状态

- **背景**：在上一行代码（填空处）中，你定义了 `ofstream f("test.txt");` 试图打开或创建一个文件。
- **原理**：C++ 的文件流对象（如 `ofstream`）重载了 `!` 运算符（或者说是转换为了布尔值）。
  - 如果文件**成功打开**，流的状态是正常的，`!f` 为假（False），`if` 里的语句不会执行。
  - 如果文件**打开失败**（例如：磁盘空间已满、没有写入权限、路径错误等），流会进入错误状态（failbit 或 badbit），此时 `!f` 为真（True），程序进入 `if` 内部。

### 2. `exit(1)`：终止程序

- **函数来源**：这是 `<stdlib.h>`（或 C++ 中的 `<cstdlib>`）库提供的函数。
- **功能**：它会强制关闭当前运行的整个程序，清理内存并关闭打开的文件流。
- **参数 1 的含义**：
  - `exit(0)`：通常表示“正常退出”（程序顺利跑完）。
  - `exit(非0值)`（如 `1`）：通常表示“非正常退出”或“错误退出”。这个数字是返回给操作系统看的，告诉系统这个程序是因为出错了才停下的。

```C++
#include<iostream>
#include<algorithm>

void fun (int input[9], int output[3][3]){
    sort(input, input + 9);
    int index = 0;
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            if (i == 1 && j == 1) {
                output[i][j] = input[8];  // 中心放最大值
            } else {
                output[i][j] = input[index++];
            }
        }
    }
```
