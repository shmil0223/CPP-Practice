### 📌 考试阅读技巧（非常重要）

- **statement ≠ expression**（英文题常考）
- **parameter ≠ argument**
- **declaration 不一定是 definition**
- **array name decays to pointer**（数组名退化为指针）
- **virtual 决定多态是否发生**

## 一、你之前问得最多的【数组 & 指针】高频英文表述补充

| English（考试常见说法）             | 中文准确理解                |
| --------------------------- | --------------------- |
| array name                  | 数组名                   |
| decays to pointer           | 退化为指针                 |
| points to the first element | 指向首元素                 |
| pointer to array            | 数组指针（如 `int (*p)[4]`） |
| array of pointers           | 指针数组                  |
| contiguous memory           | 连续存储                  |
| address of the array        | 数组的首地址                |
| pointer offset              | 指针偏移                  |
| out of bounds               | 越界                    |

⚠️ **英文题常见陷阱**

- `array name is not assignable`\
  → **数组名不可赋值**
- `p++ moves to the next element`\
  → 指针加 1 移动的是 **一个元素大小**，不是 1 字节

## 七、考试最常见【英文判断句 → 中文秒判模板】

记住下面这些，**看到就不用想**：

- `is equivalent to` → 等价于
- `results in undefined behavior` → 未定义行为（通常是错的写法）
- `is not allowed` → 不允许 / 非法
- `guarantees that` → 保证
- `may lead to` → 可能导致（⚠️ 非必然）
- `at compile time` → 编译期
- `at runtime` → 运行期
