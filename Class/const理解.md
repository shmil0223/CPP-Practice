在 C++ 中，`const` 是 **Constant**（常量/恒定）的缩写。

根据它出现的位置不同，意思也有很大的区别。针对你之前的代码 `void Time::Write() const`，我们先从这里讲起，然后再讲讲它其他的常见用法。

-----

### 1\. `const` 在函数后面：常成员函数

**代码：** `void Time::Write() const { ... }`

这是你最关心的用法。当 `const` 出现在函数参数列表的**括号后面**时，它叫**常成员函数**。

  * **含义：** 这个函数**承诺**不会修改这个对象内部的任何成员变量。
  * **通俗理解：** “只读模式”。这个函数只能读取数据（比如打印时间），绝对不能改写数据（比如修改 `hour` 或 `minute`）。

**为什么要这么做？**

1.  **安全性**：防止程序员不小心在打印函数里修改了数据。
2.  **兼容性**：如果一个对象本身被定义为常量对象（例如 `const Time t;`），那么它**只能**调用加了 `const` 的成员函数。

**示例：**

```cpp
class Time {
    int hour;
public:
    // ❌ 错误：加了 const 的函数不能修改成员变量
    void setHour(int h) const {
        hour = h; // 报错！因为承诺了只读，不能写。
    }

    // ✅ 正确：只读取，不修改
    void Write() const {
        std::cout << hour; // 没问题
    }
};
```

-----

### 2\. `const` 在变量前面：常量变量

**代码：** `const int MAX_AGE = 100;`

这是最基础的用法。

  * **含义：** 定义一个常量，初始化之后就**不能再改变**它的值。
  * **通俗理解：** “一次性赋值，终身锁定”。

**示例：**

```cpp
const int a = 10;
a = 20; // ❌ 报错！a 是只读的，不能改。
```

-----

### 3\. `const` 在引用参数里：常引用

**代码：** `void printTime(const Time& t);`

这是 C++ 中**效率最高且最常用**的传参方式。

  * **含义：** 我传递的是原来的那个对象（引用，不拷贝，速度快），但是我保证在函数里**只看不改**（加 `const`）。
  * **通俗理解：** “借我看一眼，我保证不弄坏”。

**示例：**

```cpp
// 这里的 & 表示引用（不复制，省内存）
// 这里的 const 表示只读（安全）
void checkTime(const Time& t) {
    t.Write();       // ✅ 可以调用 const 函数
    t.hour = 12;     // ❌ 报错！不能修改 const 引用指向的内容
}
```

-----

### 4\. `const` 与指针（选读，进阶）

这是考试常考、新手最容易晕的地方，记住口诀：**“看星号(\*)的位置”**。

1.  **`const int* p`** (常量指针)：

      * **指向常量的指针**。你可以改变 `p` 指向别的地址，但不能通过 `p` 去修改那个值。
      * *口诀：* `const` 在 `*` 左边，**内容**不可变。

2.  **`int* const p`** (指针常量)：

      * **指针本身是常量**。`p` 一旦指向了某个地址，就不能再指向别处了，但可以通过 `p` 修改那个值。
      * *口诀：* `const` 在 `*` 右边，**指针**不可变。

-----

### 总结一张表

| 写法 | 术语 | 含义 | 比喻 |
| :--- | :--- | :--- | :--- |
| `void f() const` | **常成员函数** | 函数内部不能改成员变量 | **“只读模式”浏览** |
| `const int a` | **常量** | 变量的值不能变 | **“焊死”的数字** |
| `const Time& t` | **常引用** | 传参时不拷贝，且不能改 | **“借来看一眼”** |
