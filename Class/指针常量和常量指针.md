这也是 C++ 中最容易搞混的概念之一。区分它们最简单的方法是：**看 `const` 和 `*` 的相对位置**。

我们可以用一句口诀来概括：**“左定值，右定向”**（或者叫“左内容，右地址”）。

这里有一个快速对照表，帮你理清思路：

-----

### 1\. 常量指针 (Pointer to Constant)

**语法：** `const int * p` 或 `int const * p`
（注意：`const` 在 `*` 的**左边**）

  * **核心含义：** 指针指向的**内容**是常量。
  * **你可以：** 改变指针指向的地址（即 `p = &b` 是合法的）。
  * **你不可以：** 通过这个指针修改它指向的值（即 `*p = 10` 是非法的）。
  * **形象理解：** 这就像你戴了一副\*\*“只读眼镜”\*\*。你可以看这行字，也可以转头看那行字（改变指向），但你不能通过眼镜去修改字的内容。

<!-- end list -->

```cpp
int a = 10;
int b = 20;
const int *p = &a; // 常量指针

*p = 30;  // ❌ 错误！不能修改值
p = &b;   // ✅ 正确！可以修改指向
```

### 2\. 指针常量 (Constant Pointer)

**语法：** `int * const p`
（注意：`const` 在 `*` 的**右边**）

  * **核心含义：** **指针本身**是常量。
  * **你可以：** 修改指针指向的值（即 `*p = 10` 是合法的）。
  * **你不可以：** 改变指针指向的地址（即 `p = &b` 是非法的）。
  * **形象理解：** 这就像你被\*\*“焊死”\*\*在了一个座位上。你必须一直坐在这个座位上（不能改变指向），但在桌子上写写画画是可以的（可以修改值）。

<!-- end list -->

```cpp
int a = 10;
int b = 20;
int * const p = &a; // 指针常量

*p = 30;  // ✅ 正确！可以修改值
p = &b;   // ❌ 错误！不能修改指向
```

-----

### 3\. 终极记忆法：就近原则

不要死记硬背中文名字（因为中文翻译有时很绕），直接看代码，使用 **“向后修饰”** 原则：

  * **`const` 后面紧跟的是什么，什么就被锁住了。**

<!-- end list -->

1.  `const int * p`

      * `const` 后面紧跟的是 `int`（数据类型）。
      * **锁住的是：** `int` 的内容。
      * **结论：** 内容不可变，指针可变。

2.  `int * const p`

      * `const` 后面紧跟的是 `p`（变量名，即指针本身）。
      * **锁住的是：** `p` 这个指针。
      * **结论：** 指针不可变，内容可变。

### 总结对比

| 类型 | 代码示例 | 这里的 const 锁住了什么？ | 能改地址吗？ (`p=&b`) | 能改值吗？ (`*p=10`) |
| :--- | :--- | :--- | :--- | :--- |
| **常量指针** | `const int * p` | **内容** (int) | ✅ 能 | ❌ 不能 |
| **指针常量** | `int * const p` | **指针** (p) | ❌ 不能 | ✅ 能 |
| **双重锁定** | `const int * const p` | **都锁住了** | ❌ 不能 | ❌ 不能 |

-----

你提到之前在看 `std::shared_ptr`，其实智能指针也有类似的用法（比如 `const std::shared_ptr<T>` 代表指针本身不能变）。
